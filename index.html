How it reads a report

Each workbook's first sheet is searched for cells labelled Product Code:, Lot Number: and Product Type:, taking the first usable value to the right, and for the result: the first number to the right of a cell mentioning ng/Day. When the code or lot labels are missing, they are taken from the file name.

The signed date comes from the signature block: a row with Signature or a … by role next to a bare Date label, read from the cell beneath. A Date Received: label in the header is ignored. An explicit Date Signed label wins; otherwise the authorizing signature beats prepared-by. Hover a date to see the signer and the prepared-by date.

Runs entirely in this browser; no data leaves the machine. All names, codes and results in the demo are fictional. Open one generated file and check the layout before relying on a batch.
